# 📱 PhoneHub - Ultimate Phone Discovery Platform

A comprehensive phone comparison and discovery web app built with HTML, CSS, JavaScript and Firebase.

## ✨ Features
- 📱 Browse 20+ phones with filters
- ⚖️ Compare phone specifications side-by-side
- 🤖 AI-powered phone finder
- ❤️ Favorites & wishlist
- ⭐ User reviews & ratings
- 📈 Price history tracking
- 🔔 Price drop alerts
- 📧 Email notifications via Brevo
- 🌙 Dark/Light mode
- 🔐 Firebase Authentication

## 🛠️ Tech Stack
- HTML/CSS/JavaScript
- Firebase (Auth, Realtime Database)
- Brevo (Email API)
- Chart.js, QRCode.js

## 🔒 Security
- API keys stored in `config.js` (not in repo)
- Rate limiting & XSS protection
- Firebase Security Rules enabled
